# TerminalCongestionViewer
Repo for all code related to my PhD project, Terminal Congestion (LiU/VTI). Feel free to open an issue or contact me if you need something.

## Usable libraries
`koda_lib.py` contains useful functions for external KoDa usage. Find an example usage in `simple_usage.py`.

## Other usable files
`uncertainty.py` contains the code used in the "data uncertainty" part of my project.
`weather_data.py` contains code processing weather-related data from SMHI.
`otherfactors_data.py` contains code for the evaluation of HDOP, tropospheric delay and ionospheric delay.
